# Technical Writing Lab

This project contains two technical writing exercises:

- **Exercise A — Python Virtual Environment:** A step-by-step guide to creating and activating a Python virtual environment, installing the `requests` package, verifying the installation, and troubleshooting a common issue.
- **Exercise B — Create a Task API Reference:** A reference for a hypothetical REST API endpoint, including request parameters, headers, JSON examples, response codes, and error handling.

## Files

- `Exercise_A_Python_Virtual_Environment.txt`
- `Exercise_B_Create_Task_API_Reference.txt`

## Note

The API endpoint and its response format are proposed examples for this exercise; they do not describe a verified live service.
